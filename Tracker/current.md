## Остаточные риски

- При production/network-раздаче frontend без Vite dev proxy нужен reverse proxy для `/api/v1`.
- Сгенерированный `frontend/playwright-report/index.html` изменен локально и не входит в последний коммит.
- После regression-прогонов есть локальные Playwright-артефакты; в коммит включать только исходные тесты, не отчеты.
- Логирование dev-запуска еще требует отдельной доработки: удобное разделение frontend/backend потоков и понятные файлы логов.
- Для точечных UI-spec использовать запуск из `frontend`: `cd frontend && npm exec playwright test tests/ui/<spec>.ts`; вариант `npm --prefix frontend exec playwright ...` из корня сейчас дает неверный контекст `baseURL`.
- Единственный текущий skip в regression связан с dataset-условием: для day-mode нужно минимум две вкладки дней.
